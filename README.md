
# Portfólio — Vinicius Albuquerque

Portfólio pessoal desenvolvido com HTML, CSS e JavaScript.

**Acesse online:** [vinicius-a.netlify.app](https://vinicius-a.netlify.app/)

## Tecnologias

- HTML
- CSS
- JavaScript

## Funcionalidades

- Layout responsivo.
- Navegação por seções.
- Tema claro e escuro.
- Preferência de tema salva no navegador.
- Links para projetos e perfis profissionais.

## Projetos

- **Academia Sistem:** sistema web para gerenciamento de alunos, treinos e exercícios.
- **Totem Museu Cícero Dias:** aplicação interativa para apresentação de conteúdos históricos e culturais.
- **Métodos Numéricos:** projeto acadêmico com algoritmos implementados em Python.

## Como executar

1. Clone este repositório.
2. Abra a pasta do projeto no VS Code.
3. Abra o arquivo `index.html` no navegador ou utilize a extensão Live Server.
