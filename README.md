# Portfólio | Vinicius Albuquerque

Portfólio pessoal desenvolvido com **HTML5, CSS3 e JavaScript**, com o objetivo de apresentar minha trajetória acadêmica, habilidades técnicas e informações de contato por meio de um site responsivo e interativo.

## Sobre o projeto

Este projeto foi desenvolvido como parte de uma atividade acadêmica da disciplina de **Programação Web e Mobile**, do curso de Ciência da Computação.

O site foi construído utilizando tecnologias fundamentais do desenvolvimento web, com arquivos HTML, CSS e JavaScript organizados separadamente.

A interface possui um design minimalista, com uma paleta de cores baseada em tons de marrom, bege e cinza, além de suporte a temas claro e escuro.

## Tecnologias utilizadas

| Tecnologia | Descrição |
|---|---|
| HTML5 | Estruturação semântica e organização do conteúdo das páginas. |
| CSS3 | Estilização, layout, responsividade e efeitos visuais. |
| JavaScript | Implementação das funcionalidades interativas e validação do formulário. |

## Funcionalidades

- **Navegação entre páginas:** menu com links para as diferentes seções do portfólio.
- **Alternância de tema:** botão para alternar entre os modos claro e escuro.
- **Mostrar mais:** funcionalidade para expandir ou recolher o conteúdo da biografia.
- **Validação de formulário:** verificação dos campos de nome, e-mail e mensagem por meio de JavaScript.
- **Feedback de formulário:** exibição de mensagens de alerta para campos inválidos e confirmação simulada de envio.
- **Ano automático:** atualização dinâmica do ano no rodapé utilizando JavaScript.
- **Efeitos visuais:** transições e animações simples nos botões.
- **Layout responsivo:** adaptação da interface para diferentes tamanhos de tela.

> O formulário possui validação no navegador e exibe uma confirmação simulada. O envio de mensagens para um servidor ainda não está implementado.

## Responsividade

O layout foi desenvolvido para se adaptar a diferentes dispositivos, incluindo desktops, notebooks, tablets e smartphones.

Para isso, são utilizados:

- Flexbox para alinhamento e organização dos elementos.
- CSS Grid para a disposição de cards e seções.
- Media Queries para adaptar o layout conforme a largura da tela.
