## Tecnologias

- HTML5
- CSS3
- JavaScript

## Funcionalidades

- Páginas separadas para início, sobre, habilidades, projetos e contato.
- Layout responsivo para desktop, tablet e celular.
- Tema claro e escuro, com preferência salva no navegador.
- Links para projetos, repositórios e perfil profissional.
- Ano atualizado automaticamente no rodapé.
- Estrutura sem dependências de frameworks.

## Projetos apresentados

- **Academia Sistem:** sistema web para gerenciamento de alunos, treinos e exercícios com API REST.
- **Totem Museu Cícero Dias:** aplicação interativa de conteúdo histórico e cultural para uso presencial.
- **Métodos Numéricos:** projeto acadêmico em Python.
- **Portfólio pessoal:** este site.

## Executar localmente

Clone o repositório e abra `index.html` no navegador. Para desenvolvimento, também é possível usar a extensão Live Server do VS Code.
