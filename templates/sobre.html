Quem sou

Sou estudante de Ciência da Computação na Universidade Católica de Pernambuco (UNICAP) e venho desenvolvendo projetos para transformar o conteúdo dos estudos em prática.

Meu principal interesse é o desenvolvimento backend: criar APIs, organizar regras de negócio, trabalhar com bancos de dados e entender como as partes de uma aplicação se conectam.

Tenho praticado Python, FastAPI, SQL e desenvolvimento web. Também trabalho com HTML, CSS e JavaScript para construir interfaces que consomem APIs.

Já participei do desenvolvimento de uma aplicação interativa para o totem do Museu Cícero Dias, em Escada–PE, e desenvolvo projetos acadêmicos e pessoais para aprimorar minha organização de código, validação de dados e integração com bancos relacionais.

Meu objetivo é continuar evoluindo tecnicamente e buscar oportunidades em desenvolvimento de software nas quais eu possa contribuir, aprender com outras pessoas e ganhar experiência prática.
